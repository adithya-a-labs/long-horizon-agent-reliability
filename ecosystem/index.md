# Ecosystem Analysis

The ecosystem section studies implementation and documentation sources from the Notion corpus. It asks how systems represent state, allocate execution authority, retry work, resume after interruption, expose traces, and permit intervention.

These sources establish implemented or documented mechanisms. They do not establish scientific improvements in agent reliability.

## Files

- [workflow-systems.md](workflow-systems.md): detailed Temporal/Airflow/Trigger.dev/LangGraph comparison and transfer analysis.
- [agent-harnesses.md](agent-harnesses.md): implementation patterns in agent frameworks and reference agents.
- [tool-contracts.md](tool-contracts.md): structured outputs, function calls, and the boundary between syntax and truth.
- [comparison-matrix.md](comparison-matrix.md): compact map of all relevant non-paper sources.
