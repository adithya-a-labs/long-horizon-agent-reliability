# Provenance

This directory records where the repository's claims come from, how sources were classified, and where access or evidential gaps remain.

The starting corpus is the complete 51-record [Notion Document Hub](https://www.notion.so/3edf975653bf833b9c490161834cfa41?v=171f975653bf8387a73d887d21231b86&source=copy_link), audited on 16 August 2026. The Notion corpus is a starting knowledge base, not evidence that the broader field has been exhaustively searched.

## Files

- [source-inventory.md](source-inventory.md): all Notion records, categories, deduplication, and source roles.
- [access-log.md](access-log.md): what was fully, partially, or not reviewed.
- [claim-evidence-map.md](claim-evidence-map.md): rules and a living mapping from repository claims to supporting evidence.
- [final-audit.md](final-audit.md): implementation-time claim, citation, structure, and link audit.

No copyrighted paper PDFs are stored in this repository.
